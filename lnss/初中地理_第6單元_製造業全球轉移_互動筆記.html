6.1
甚麼是製造業？
A 四大產業種類
第一
初級產業

開採和採集天然資源作原材料
例：農業、採礦、捕魚

第二
製造業（Secondary）

把原料或半製品製成製品
例：紡織、汽車廠

第三
服務業（Tertiary）

為其他行業或人士提供服務
例：零售、醫療、教育

第四
資訊業（Quaternary）

處理資訊和進行不同類型的研究工作
例：研究、IT、顧問

C 製造業的區位因素

製造業廠商需要容易取得各種不同的投入來生產製品，製品製成後也要尋找市場銷售製品。這些影響製造業決定在哪裏生產製品的因素稱為工業區位因素。

👷

勞工

需要大量工人從事裝配工作

例：電腦裝配業 → 主要區位因素：勞工
🌾

原料

原料易腐，工廠必須在原料腐壞前進行加工

例：煉糖業（甘蔗易腐） → 主要區位因素：原料
🏪

市場

汽水添加了大量水，產品變得重，接近市場可降低成本

例：汽水製造業 → 主要區位因素：市場
🛬

土地

原料、機器和製品均佔用大片土地

例：飛機製造業 → 主要區位因素：土地

3

結論：香港製造業的重要性逐漸下降。

B 香港製造業區位轉移的歷程
1950年代至1970年代中期
影響因素：內地移民為香港提供技術、資金和勞工；香港有良好的港口和自由港政策
分佈：輕工業和勞力密集工業主要在維多利亞港兩岸的主要市區發展
1960至70年代中期：工廠分佈擴展到鄰近市區的屋邨，以便聘請勞工
1970年代中期
影響因素：主要市區的租金大幅上升
分佈：工廠遷往新市鎮或近郊的工業邨或工業區，因為那裏的租金較低
1980年代至2000年代初期（趨勢1）
在珠江三角洲區域：工資和租金較低廉；污染管制寬鬆；實施開放政策
在香港：效率高；海外運輸網絡完善；法制健全；教育水平較高
結果：大多數製造業（尤其是勞力密集工業）遷移到廣東珠江三角洲區域；總部留在香港
1980年代至2000年代初期（趨勢2）
影響因素：香港政府推動高科技工業
結果：發展高增值和科技密集工業；設立香港科學園和數碼港等研究和發展中心
2000年代初期至今（趨勢1）
影響因素：珠江三角洲區域的工資、租金和能源價格上漲；加強污染管制；其他地區廉價勞工和低廉租金具吸引力
結果：珠江三角洲區域的勞力密集工業遷移到廣東內陸地區、中國內陸省份、南亞或東南亞等欠發達國家
2000年代初期至今（趨勢2）
影響因素：廣東政府致力提升珠江三角洲區域工業結構級數
結果：生產高增值製品；實行自動化生產；部分工業仍留在珠江三角洲區域
C 香港生產模式的改變
時期生產模式分工特點
1980年代以前 單邊區位生產 所有製造業活動在同一地點進行
1980年代以後 多邊區位生產 製造業活動在不同地點進行：
• 工廠在珠江三角洲區域或中國內地（低技術：加工、裝配）
• 位於香港的總部負責行政管理、設計、研究和發展、市場推廣

B 製造業活動是否出現全球轉移？

中國（欠發達國家）佔全球製造業總產值的百分比（↑上升），而美國、日本和德國（較發達國家）所佔的百分比（↓下降）。

C 甚麼因素導致製造業活動的全球轉移？
1 欠發達國家的吸引力
a 成本低

工資、租金和營運成本都較低

b 政府政策
  • 中國的經濟特區
  • 墨西哥的加工出口工廠
c 新興市場

部分欠發達國家（如中國）的生活水平提高，成為很多製品的新興市場

2 促成因素
a 運輸設備改進

先進的大型貨輪和油輪節省了運輸成本和時間，製品的成本也因而下降→ 製造業活動選址的自由度增加

b 資訊與通訊科技發展

廣泛應用互聯網使資訊快速流通 → 更容易管理海外的工廠

c 跨國企業

跨國企業採用多邊區位生產；遍及全球，可輕易地把製造業活動轉移到低成本的區位，以賺取最高利潤

3 跨國廠商有助促進製造業活動的全球轉移

a 全球規模的分工

  • 較發達國家：總部、高技術製造、研究和發展、設計、高科技生產
  • 欠發達國家：低技術製造（加工和裝配）

b 全球網絡供應商

  • 大批購入原料
  • 可向供應商爭取較低價格
  • 可接觸到世界各地收費最廉宜的供應商
6.4
製造業活動的全球轉移帶來甚麼好處和壞處？
A 對有工廠遷出的國家（以美國大湖區為例）

✅ 好處／得益

  • 製造業廠商：生產成本降低；製品更有競爭力
  • 消費者：可以買到便宜的貨品
  • 社會和民眾：集中資源發展高增值生產或服務；提高勞工的生產力和民眾的生活水平
  • 環境：環境變得潔淨，污染減少

❌ 壞處／衍生問題

  • 製造業工人：就業機會和收入減少 → 導致家庭和社會問題；社會動盪
  • 社會和民眾：當地民眾在商品和服務上的消費（↓）；當地政府稅收（↓）
  • 衍生問題：經濟衰退；基礎設施和社會服務質素下降
大湖區製造業職位流失（1990–2015年）
  • 大湖區九個州之中，六個的製造業職位流失率高於全國平均值
  • 製造業活動的全球轉移對大湖區：影響嚴重
A 對有工廠遷入的國家（以中國珠江三角洲區域為例）

✅ 好處／得益

  • 社會和民眾：提高技術水平；就業機會和收入（↑）
  • 政府稅收（↑）：帶動當地民眾消費；改善基礎設施和社會服務

❌ 壞處／衍生問題

  • 環境：自然環境和農地消失；污染問題
  • 社會：損害當地民眾的健康
  • 經濟：阻礙經濟發展；需要大量金錢淨化環境
6.5
工業發展能夠更加可持續嗎？
A 可持續的工業發展原則

💰 a 經濟發展

  • 當地經濟穩定發展

🤝 b 社會發展

  • 社會每一分子均可參與工業發展，提供技術訓練
  • 每人均可合理地分享到工業發展的成果，透過提供社會援助

🌿 c 環境保育

  • 盡量減少製造業的環境污染
B 怎樣紓緩工業區位轉移帶來的問題？
有工廠遷出的國家／地區（美國大湖區）

吸引新的投資

  • 給廠商提供稅務優惠
  • 把舊工業用地重新發展為高科技汽車製造中心
  • 改善基礎設施，例如改善連接港口和鐵路網絡
  • 為製造業吸納創科資金

增加製造業廠商的競爭力

  • 再培訓工人，讓他們適應科技轉變
  • 在研究和發展方面增加投資，生產較環保的製品
  • 改善基礎設施
有工廠遷入的國家／地區（中國珠江三角洲區域）

減輕污染問題

  • 把污染嚴重的製造業活動遷移到內陸沿海省份
  • 立例管制工廠須先處理好廢氣和污水，才能排放

鼓勵發展高增值和潔淨工業

  • 提供誘因鼓勵製造業廠商使用新的節能機器
  • 為新工業招攬和培訓人才
  • 發展工業園，吸引高增值和高科技製造業（即潔淨工業）

答：原料（甘蔗易腐，工廠必須在腐壞前加工）（A）
汽水製造業的主要區位因素是甚麼？
答：市場（汽水添加大量水，產品變重，接近市場可降低成本）（C）
1976年至2014年，香港製造業工人佔總工作人口的百分比有何變化？
答：由46%下降至7%（D）

答：主要市區租金大幅上升（B）
1980年代後，香港採用甚麼新的生產模式？
答：多邊區位生產（C）
在多邊區位生產下，哪些職能留在香港？
答：總部負責行政管理、設計、研究和發展、市場推廣（A）
世界主要工業區的分佈有何特點？
答：不平均，大部分在較發達國家（B）
製造業活動全球轉移的總體方向是？
答：由較發達國家轉移到欠發達國家（C）
運輸設備改進對製造業區位選址有甚麼影響？
答：降低運輸成本，製造業活動選址的自由度增加（A）
製造業遷移對遷出國的環境有甚麼好處？
答：環境變得潔淨，污染減少（D）
可持續工業發展包括哪三大原則？

珠江三角洲區域為減輕污染問題，採取了哪些措施？
答：把污染嚴重工業遷往內陸、立例管制廢氣和污水排放（B）
