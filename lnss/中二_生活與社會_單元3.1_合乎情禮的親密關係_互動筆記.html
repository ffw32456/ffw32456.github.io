1 友誼和戀愛的異同

戀愛建基於友誼之上，情侶之間會有強烈的愛意，渴望有親密的接觸，並對彼此的親密關係有所承擔。

2 甚麼是戀愛？——「愛情三角」理論
「愛情三角」理論：健康戀愛關係應具備親密、激情和承諾三個元素

在戀愛的不同階段，三個元素的分量比重會出現變化；只有三個元素達到平衡，才能發展出穩定而長久的愛情關係。

親密
  • 是愛情中的情感部分
  • 雙方互相信賴和補諒，尋求親密的感覺
激情
  • 愛情中的動機部分
  • 雙方會產生浪漫的感覺和情慾的追求
承諾
  • 是愛情中的理性部分
  • 專一向對方付出感情，與對方維持長久的關係
  • 願意承擔愛的責任
2.2 戀愛應抱持的態度——戀愛的目的
A

滿足情感所需

青春期的生理改變促使青少年容易受到異性吸引，友誼已不能滿足在愛與被愛的情感需要，於是懂憬愛情，希望尋求更親密的關係。

B

分享人生

在戀愛中，雙方可以互相傾訴、分享自己的經歷和感受，共同度過生活中的喜與憂，在心靈上得到滿足和煎熬。

C

互相扶持

戀愛雙方能互相鼓勵、互相扶持；令彼此更有勇氣與力量面對人生中的各種困難和挑戰。當遇上問題時，伴侶可以共同商議和解決，一起成長。

D

建立家庭

戀愛是婚姻的起點，是兩個人互相了解、互相吸引的過程。當戀愛昇華後，兩人便希望締結婚姻，建立家庭，進入共同的人生旅程。

2.3 戀愛應抱持的態度——應有態度
A

互相支持

  • ✓ 應多了解對方的需要和感受，主動關心和幫助對方
  • ✓ 應在順境時一起分享，在逆境時一起面對，共同學習和成長

  • ✓ 應該容許彼此有各自的生活空間和自由
  • ✓ 應重視平等，尊重對方的想法和感受

  • ✗ 不做傷害對方的事情

  • ✓ 雙方應彼此付出，向對方作出承諾，誠實、專一，承擔作為戀人的責任
3 戀愛關係結束的因素與處理方法
3.1 導致戀愛關係結束的因素

A 個人因素

  • 性格和價值觀不合：雙方可能發現彼此在個性、興趣、價值觀上有很大差異，因而容易產生衝突，甚至分手
  • 感情轉淡：戀愛初期充滿激情，但新鮮感退減，感情由熱情逐漸轉為平淡；若雙方無意維繫感情，最終便會分手
  • 第三者介入：若其中一方移情別戀，雙方之間的互信和尊重會被破壞，戀愛關係亦難以維持
  • 學業或工作壓力：缺乏時間跟對方見面和維繫感情，致使感情終結

B 家庭因素

青少年處於求學階段，心智或尚未成熟，父母可能擔心子女過分投入戀愛關係，為其學業和身心帶來負面影響，因而干預甚至阻止，以致戀愛關係終結。

C 經濟因素

談戀愛難免涉及消費支出。大部分青少年在經濟上仍然依賴父母，若一方未能滿足對方的物質需求時，二人會產生摩擦和爭執，影響感情。

3.2 戀愛關係結束的處理方法
A

坦誠交代原因

  • ✓ 以認真、坦誠的態度向對方清楚交代分手原因，期望對方能夠接納，和平分手
  • ✗ 避免指責、抨擊、侮辱，或將責任推予對方，要顧及對方的感受
B

選擇合適日子

  • ✓ 提出分手前，應預先給予對方暗示或信號，讓對方有心理準備
  • ✗ 不應在情人節、相識紀念日等特別日子提出分手
C

注意分手方式

  • ✓ 應抱持明確、堅定的態度，避免免棄棋不定或拖泥帶水
  • 假若對方的情緒較易波動，我們可用書信或電話等通訊形式提出分手，減低對對方的刺激
D

選擇安全場合

  • ✓ 應選擇安全的分手地點，例如熟悉和開揚的公共場所
  • ✗ 不要在幽靜或二人獨處的場所提出分手，以免對方在情緒波動下，作出傷害自己或他人的行為

青少年與親密關係
1 戀愛與性
1.1 性與感情基礎
愛、性與婚姻——三者的關係是密不可分的
愛
  • 是建立一段感情關係的元素，透過與喜歡的人建立親密關係，追求心靈上的親愛
性
  • 必須建基於有堅實基礎和承諾的愛，才能保障雙方的幸福
婚姻
  • 是對戀人的承諾，向對方表示要維持穩定、長久的愛的決心
1.2 拒絕婚前性行為
  • 忠誠和保持貞潔，是對戀人的尊重
  • 輕率地發生性關係會削弱彼此的信任，影響未來的婚姻生活
  • 性行為應緊扣婚姻承諾，在婚前保持貞潔，這有助建立健康、長久的感情關係
1.3 愛的表達方式

表達愛意的方式有很多，例如：

  • ① 向對方說欣賞及讚美的話
  • ② 投入時間讓雙方培養感情，如逛街、看電影等
  • ③ 付出時間服務對方，如做家務、帶寵物散步等；身體接觸，如牽手、擁抱等

→ 性只是其中一種表達愛意的方式。

2 訂定親密界限的重要性及方法
2.1 訂定親密界限的重要性
A

維繫戀愛關係

在戀愛關係中，假如其中一方做出過分的親密行為，可能會令對方受驚、反感，或感到不受尊重，破壞戀愛關係。→ 戀愛雙方應訂定親密界限，加強彼此的溝通和了解，有助維繫雙方的戀愛關係。

B

保障身心健康

  • 性應在婚姻內，向最親密和最信任的人展現，否則戀愛關係一旦破裂，會對心靈造成很大的傷害和遺憾
  • 與患有性病的人進行性接觸，有機會感染性病，損害身體健康
  • → 訂定親密界限可避免輕率的性接觸，有助保障身心健康
C

避免意外懷孕

青少年因一時衝動而發生性行為，可能會引致意外懷孕。→ 訂定親密界限，有助避免意外懷孕。

2.2 訂定親密界限的原則和方法
A

注重感情基礎

  • 應了解親密關係必須建基於深厚和穩定的感情基礎上，以性來維繫感情而忽略心靈的溝通，關係難以持久
  • → 戀愛雙方應多了解對方的感受和需要
  • → 以互相尊重和平等對待的態度去處理親密關係
B

展開坦誠溝通

  • 應坦誠、認真地展開對話：
  • ① 明確表達自己的意願
  • ② 說明自己的想法和理由
  • ③ 細心聆聽對方的觀點
  • → 為親密行為訂定雙方認同的界線和規則，確保雙方都能夠理解和遵守
C

符合家庭與社會期望

  • 社會普遍認為婚前性行為是越軌的行為，青少年不應隨意與異性發生性行為
  • 青少年訂定親密界限時應考慮父母的期望，以維護家庭的和諧
D

遵守法律規範

香港法例規定，任何人與16歲以下女童發生性行為，即使對方自願，亦屬違法，一經定罪，可被判處監禁。→ 青少年不應因一時衝動而胡亂發生性行為。

3 性幻想和性衝動的處理方法

3.1 甚麼是性幻想？

  • 性幻想是指腦海中浮現與性有關的情境和事物
  • 可在一定程度上滿足個人的性慾望，有助青少年舒緩性成熟所帶來的壓力
  • 性幻想本身是沒有危害的，但過度沉溺會令青少年脫離現實，妨礙正常社交和損害精神健康

3.2 甚麼是性衝動？

  • 性衝動是指因身體受到觸覺、視覺、聽覺和心理因素等刺激而產生對性行為的渴求和需要
  • 性衝動是青春期常見和正常的生理反應，青少年不必為此感到焦慮或內疚
  • 青少年應保持理性、克制，學習控制和處理性衝動
3.3 處理性幻想和性衝動的方法
A

避免親密接觸

  • 身體上的接觸，如接吻、擁抱等，均容易引起性幻想和性衝動
  • → 與戀人訂立親密界限，避免有過分親密的身體接觸
B

減少獨處機會

  • 二人獨處的環境較容易誘發性幻想和性衝動
  • → 避免在家中、渡假屋、幽靜僻靜的公園等較易降低個人防線的地方與戀人單獨共處
C

遠離色情媒體

  • 感官上的刺激容易令青少年產生性幻想和性衝動
  • → 謝絕各類色情資訊，例如色情電影和色情刊物；也不應透過互聯網接觸或搜尋色情資訊
D

參與羣體活動

  • 可相約朋友做運動，透過消耗體力來緩解性慾
  • 可參與義務工作、羣體聚會等，把注意力轉移到其他事情上
  • → 減少性幻想和性衝動
第三部分
不恰當處理親密關係的後果
4.1 不恰當處理親密關係的情況

A 情緒勒索

  • 情緒勒索是一種情感操控行為
  • → 勒索者企圖以愛之名來威脅、控制他人接受自己的想法和觀點，或迫對方做出不願意的事情
  • → 被勒索者重視彼此的關係，關心對方的感受，或感到恐懼、內疚而屈服去滿足對方的要求和作出退讓

B 戀愛暴力

  • 戀愛暴力是指在戀愛關係中，一方針對另一方的任何蓄意的言語、身體、精神或性的過度控制、傷害和攻擊
  • 部分青少年情侶在戀愛期望、親密關係界線等方面出現分歧，或缺乏有效溝通，而與戀人發生衝突，容易導致戀愛暴力

類型描述

肢體暴力 拳打腳踢、掌摑、推撞、用武器攻擊等
精神暴力 控制戀人的社交自由、偷看其網上聊天記錄、阻礙追求個人興趣等
性暴力 以各種方式威脅戀人發生性行為、以暴力要脅對方答應自己的性要求等
4.2 不恰當處理親密關係的後果

A 損害身心健康

  • 戀愛暴力會對受害者造成身心傷害
  • 在戀愛中若出現情緒勒索，被勒索者為滿足勒索者的要求，往往會壓抑自己的需求和情感，容易產生沮喪、焦慮、不安等情緒，造成情緒困擾

B 可能感染性病

  • 與患有性病的伴侶進行親密性接觸會感染性病，包括淋病、梅毒、愛滋病等
  • 即使在性接觸的過程中使用安全套，也未必可以完全排除感染性病的可能性

C 導致未婚懷孕

  • 婚前性行為可能引致意外懷孕，令未婚少女要休學產子，影響學業
  • 倘若選擇墮胎，不但會對未婚少女造成心理創傷，相關手術也可能對身體造成重大傷害

D 造成家庭問題

  • 未婚懷孕容易引起雙方家人的反感和責備，社會和親友的非議→ 造成更大的家庭矛盾和衝突
  • 一些年青情侶因意外懷孕而奉子成婚，但他們缺乏經濟基礎及做父母的心理準備，容易導致更多家庭問題，以致婚姻破裂

E 負上法律責任

  • 青少年如果因一時衝動發生性行為，男方可能觸犯相關法例，須負上刑事責任
  • 若出現戀愛暴力，施虐者或會觸犯襲擊、性侵犯或非法禁錮等罪行，也須接受法律制裁，前途盡毀
