第一部分
網絡硬件設備
網絡界面卡 NIC

Network Interface Card

  • 內置於主機板或插入擴展槽
  • 為電腦提供網絡連接功能
  • 有線 LAN 或無線 (Wi-Fi)
交換器 Switch

Switch

  • 在LAN 內把多台電腦、打印機及伺服器連接在一起
  • 根據 MAC 位址傳送數據
路由器 Router

Router

  • 把兩個或以上的 LAN 連接起來
  • 使訊息可在不同 LAN 之間傳送
  • 根據 IP 位址傳送數據
寬頻數據機 Modem

Broadband Modem

  • 路由器 WAN 埠連接至寬頻數據機
  • 連接至 ISP 網絡上網
無線網絡接達點 WAP

Wireless Access Point

  • 讓無線裝置連接至有線LAN
  • 提供 Wi-Fi 訊號
雙頻路由器

2.4 GHz vs 5 GHz

  • 2.4 GHz：覆蓋範圍較大，穿牆能力較強，速度較慢
  • 5 GHz：速度較快，覆蓋範圍較小
  • 隔牆遠距離 → 選2.4 GHz
傳輸媒介比較
傳輸媒介英文簡稱速度電磁干擾傳輸距離
無屏蔽雙扭線 UTP 一般 較易受干擾 較短
光纖 Optical Fibre 更快 較少電磁干擾 更長

光纖相對於 UTP 電纜的優點：數據傳輸速度更快、較少受電磁干擾及可作更長距離傳輸。

第三部分
TCP/IP 通訊協定
TCP 傳輸控制協定

TCP（傳輸控制協定）：負責把數據分割成數據包，傳送到目的地後再重新組合。

TCP 重傳機制（確認回應）
1
發送者把數據包傳送給接收者
2
接收者收到後，回傳「確認回應」（Acknowledgement）給發送者
3
若發送者在預定時間內沒有收到確認回應 → 自動重新傳送該數據包
應用層協定
協定全名用途
HTTP 超文本傳輸協定 瀏覽網頁
HTTPS 超文本傳輸安全協定 加密瀏覽；驗證伺服器身份（配合數碼證書）
FTP 檔案傳輸協定 在互聯網上的電腦與伺服器之間上載及下載檔案
FTPS 安全檔案傳輸協定 加密版 FTP（比 FTP 安全）

DNS 運作步驟
1
用戶電腦向 DNS 伺服器發送查詢，詢問目標網站的 IP 位址
2
DNS 伺服器在數據庫中查找紀錄，並把相應的 IP 位址傳回用戶電腦
3
用戶電腦根據取得的 IP 位址，向目標網頁伺服器發送 HTTP/HTTPS 網頁請求
4
網頁伺服器處理請求後，把所需的網頁內容傳回用戶電腦顯示
第五部分
IP 位址：IPv4 與 IPv6

IPv4

  • 由 32 位元組成
  • 以十進制表示，以「.」分隔
  • 共約 43 億個位址
  • 例：
    172.16.254.1
  • 無效例（第三組超過255）：
    192.168.320.1 ✗

IPv6

  • 由 128 位元組成
  • 以十六進制表示，以「:」分隔
  • 位址數量遠多於 IPv4
  • 例：
    fe80:0000:0000:0000:3db4:6713:5361:e334
  • 無效例（含「g」非法字元）：
    2001:0db8:85g3:… ✗

⚠️ 為甚麼需要 IPv6？隨着互聯網迅速發展，大部分 IPv4 位址都已被使用，因此需要制定 IPv6 以提供大量 IP 位址滿足需求。

第六部分
網絡工具指令
PING 指令

功能

  • 測試兩台電腦能否互相通訊
  • 透過 DNS 查出目標網站對應的 IP 位址
  • 用法：在 Windows 終端機輸入 PING [網域名稱]
第七部分
資訊保安
A 惡意軟件類型

🦠 電腦病毒

  • 附在正常程式或檔案中
  • 會自我複製
  • 需要宿主程式才能傳播

🪱 電腦蠕蟲

  • 可在網絡上獨立傳播
  • 無需宿主程式
  • 會自我複製

🐴 木馬程式

  • 偽裝成正常軟件
  • 不自我複製
  • 建立後門讓黑客遠程控制
  • 竊取資料

📢 廣告軟件

  • 強制顯示廣告
  • 可能收集瀏覽習慣

🔑 試題關鍵：「不自我複製」、「偽裝正常軟件」、「建立後門」→ 木馬程式（Trojan）

B 網絡保安技術與設備
🔀

交換器 Switch

在 LAN 內連接多台電腦、打印機及伺服器（配對：B）

🔀

路由器 Router

把兩個或以上的 LAN 連接起來，使訊息可在不同 LAN 間傳送（配對：A）

🛡️

防火牆 Firewall

根據預設保安規則限制網絡流量，防止外部網絡未經授權存取內部電腦或封鎖惡意網站（配對：D）

🔒

VPN 虛擬私有網絡

透過專用伺服器建立加密連線，並屏蔽發送者的真實 IP 位址（配對：C）

📱

雙重認證 2FA

登入時要求同時提供「密碼」及「手機短訊驗證碼／保安編碼器安全碼」（配對：E）

🔐

HTTPS / 數碼證書

驗證伺服器身份及把數據加密，防止黑客截聽；瀏覽器顯示「🔒 鎖頭圖示」

C 網絡欺詐類型

仿冒詐騙 Phishing

利用虛假網站誘騙受害者透露敏感個人或財務資訊（如信用卡號碼）

拒絕交付詐騙

賣家在網絡拍賣收款後，永遠不發貨的互聯網欺詐

DDoS 分布式拒絕服務攻擊

利用大量電腦同時向目標伺服器發送大量請求，使其無法正常運作

AI 生成作品的版權爭議

爭議原因一

AI 在生成作品時，可能未經版權擁有人同意下使用了受版權保護的作品作訓練

爭議原因二

AI 生成的作品並非由人類創作，版權誰屬存在爭議（AI？使用者？開發者？）
